# 乐伴 LeBan — ESP32-C3 桌面陪伴机器人（用药提醒）

> 把提醒，变成陪伴。一台巴掌大小、整机成本约百元的桌面陪伴机器人，面向独居老人用药提醒场景。

参赛作品编号：CSZ1010736（第八届中国高校智能机器人创意大赛 · 综合赛道）

## 功能特性

- **多模态提醒**：到点触发「文字图标 + OLED 表情 + 原地晃动」三重提醒，不依赖声音
- **遗忘保护**：未确认提醒自动升级——晃动力度三档增强 + OLED 10 Hz 反色闪烁，按 1/3/5 分钟三轮重试后放弃，等待下个时间点
- **WiFi 网页面板**：AP 模式热点 `DeskRobot`，手机浏览器直连 `192.168.4.1` 即得 14 个中文按钮控制面板（提醒触发 / 表情回应 / 运动调试 / 转速调节），无需安装 App
- **串口指令通道**：115200 bps，单字母指令完成全部调试与确认（维护人员通道）
- **六种状态表情**：笑脸 / 跑步 / 胶囊 / 点赞 / 爱心 / 晚安，全部像素级手绘渲染，无字库依赖
- **NVS 断电记忆**：直行纠偏值、行驶转速掉电不丢
- **NTP 可选校时**：联网自动校准软时钟，断网纯离线照常提醒
- **量产预留**：GPIO4 轻触按键确认逻辑已内置（40 ms 防抖 + 开机静默期抗 RF 干扰），接上按键即实现老人零手机操作

## 硬件平台

| 模块 | 型号 | 说明 |
|---|---|---|
| 主控 | ESP32-C3（RISC-V 单核 160 MHz） | 国产乐鑫芯片 |
| 显示 | 0.96" SSD1306 OLED（I2C 0x3C） | 128×64 |
| 驱动 | L298N 双 H 桥 | VM 入口 100 μF + 0.1 μF 双电容去耦 |
| 电机 | N20 减速电机 ×2（左右轮镜像安装） | 3 V 额定 |
| 电源 | 单节 18650（7400 mWh）+ Type-C 充放电升压模块 | 升压 5.0 V ± 0.1 V |

## 引脚定义

| 引脚 | 功能 |
|---|---|
| GPIO3 / GPIO2 | L298N IN1 / IN2（左轮） |
| GPIO1 / GPIO21 | L298N IN3 / IN4（右轮） |
| GPIO8 / GPIO9 | I2C SDA / SCL（OLED） |
| GPIO4 | 轻触按键（量产预留，当前未接入） |

> 注意：GPIO9 为 ESP32-C3 strapping 引脚，代码已在启动后显式 `INPUT_PULLUP` 保护。

## 编译烧录

1. Arduino IDE 安装 **esp32 by Espressif Systems** 开发板支持包（v3.0.x）
2. 开发板选择 **ESP32C3 Dev Module**
3. 依赖库（库管理器安装）：`NTPClient`
4. 打开 `LeBan_Robot.ino`，直接上传

无任何 WiFi 凭证硬编码：默认纯 AP 离线模式运行；如需 NTP 联网校时，在 `staNetworks[][]` 中填入自家 WiFi。

## 串口指令表（115200 bps）

| 指令 | 功能 |
|---|---|
| `T` | 触发吃药提醒 |
| `K` | 确认提醒（等同网页面板点赞/爱心） |
| `1`~`6` | 切换表情（笑脸/胶囊/跑步/月亮/点赞/爱心） |
| `F`/`B`/`L`/`R`/`S` | 行驶调试：前进/后退/左转/右转/停止 |
| `[` / `]` | 直行纠偏 ∓5（存 NVS） |
| `C` | 强制整屏大时钟 |
| `N` | 手动 NTP 校时 |

## 关键设计说明

- **PWM 软启动斜坡**（`rockRamp()`）：换向前先降速回零、加速每步 +10、约 125 Hz 刷新——消除单节 18650 供电下电机起步浪涌，实测杜绝欠压（brownout）重启
- **三通道共用一个状态机入口**：网页面板、串口、物理按键走同一确认路径，通道可替换
- **提醒力度分级**：`rockTick()` 三档力度随遗忘等级增强，单节电池下主动限制峰值电流防掉压
